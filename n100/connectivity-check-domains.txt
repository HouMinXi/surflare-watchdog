# Connectivity check domains for tombstone bypass
# These domains are appended to /etc/smartdns/domain-set/cn_domain_flat.txt
# on the N100. SmartDNS resolves them and adds IPs to cn_domain_ips
# nftset (both sw_lan_tproxy and killswitch tables).
#
# During tombstone, these IPs bypass the REJECT rule (via
# ip daddr @cn_domain_ips -> return in prerouting) and are allowed
# through the FORWARD chain (ip daddr @cn_domain_ips -> accept in
# killswitch). This prevents protected devices from showing
# "no internet" during VPN reconnects.
#
# Deploy: append these to cn_domain_flat.txt and restart SmartDNS.
captive.apple.com
www.msftconnecttest.com
connectivitycheck.gstatic.com

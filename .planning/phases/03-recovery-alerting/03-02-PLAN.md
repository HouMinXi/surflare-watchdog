  </read_first>
  <action>
    REC-05: Create scripts/test_killswitch_forward.sh that verifies the
    killswitch forward chain is functioning correctly.

    The test runs on N100 via SSH.  It verifies:
    1. inet killswitch table exists
    2. forward chain exists with policy accept (implicit block via reject rule)
    3. LAN reject rule present at chain end (iifname "br-lan" reject)
    4. server_ips accept rule present (iifname "br-lan" ip daddr @server_ips)
    5. bypass_ipv4 set non-empty (at least one entry)
    6. output chain exists with mark 0x1 and 0xff accept rules

    NOTE: forward chain uses policy accept + explicit reject (not policy drop).
    LAN traffic not matching any accept rule hits the reject rule at chain end.
    VPN mark 0x1 is in the OUTPUT chain, not forward -- LAN traffic goes
    through tproxy to the local proxy, which sends it out via output chain.

    The test is read-only (nft list only, no rule modifications).
    Exit 0 = all checks pass, exit 1 = any check fails.

    Script structure:
      #!/usr/bin/env bash
      set -euo pipefail
      N100="root@192.168.100.1"
      FAIL=0
      check() { if ! ssh "$N100" "$1"; then echo "FAIL: $2"; FAIL=1; else echo "OK: $2"; fi }

      check "nft list table inet killswitch >/dev/null 2>&1" "killswitch table exists"
      check "nft list chain inet killswitch forward 2>/dev/null | grep -q 'policy accept'" "forward chain exists"
      check "nft list chain inet killswitch forward 2>/dev/null | grep -q 'br-lan.*reject'" "LAN reject rule (implicit block)"
      check "nft list chain inet killswitch forward 2>/dev/null | grep -q '@server_ips'" "server_ips accept rule"
      check "nft list set inet killswitch bypass_ipv4 2>/dev/null | grep -qE '[0-9]+\.[0-9]'" "bypass_ipv4 non-empty"
      check "nft list chain inet killswitch output 2>/dev/null | grep -q 'mark 0x00000001'" "output mark 0x1 accept"
      check "nft list chain inet killswitch output 2>/dev/null | grep -q 'mark 0x000000ff'" "output mark 0xff accept"

      exit $FAIL
  </action>
  <verify>

    Manual: run the test on N100 and verify all checks pass
  </verify>
  <done>Killswitch forward chain smoke test created and passes</done>

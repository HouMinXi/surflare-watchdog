<objective>
Fix two stability gaps in surflare_watchdog.sh: (1) sing-box resets its fd
limit to 1024 on startup, overriding the inherited 65535; (2) background
spawns (tcpdump + 11 sleep commands) inherit fd 200 (the instance lock),
preventing watchdog restart when the old process exits while a child holds
the lock. Also add stop_packet_trace to cleanup() so the tcpdump is killed
on watchdog exit.

Purpose: SC1 ensures sing-box can handle >1024 concurrent connections.
SC2 ensures procd can always restart the watchdog by releasing the
instance lock fd 200 on all code paths.

Output: Modified surflare_watchdog.sh with prlimit helper + call sites,
200>&- on all background spawns, and stop_packet_trace in cleanup().
</objective>
